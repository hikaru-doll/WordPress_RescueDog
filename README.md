## 工夫したこと
WordPress学習初期に制作したサイトを修正したものです。  
必要な情報へスムーズに到達できるよう、構成を見直てサイト設計しました。  
里親希望者が知りたい情報（保護犬の紹介、譲渡までの流れ、譲渡の条件）へ迷わずアクセスできる導線にしました。  
ACF（Advanced Custom Fields）を活用し、管理者が専門知識なしでも保護犬情報を入力・更新しやすいように工夫しました。  
継続的な情報発信によって、施設の活動や保護犬たちの状況を伝えられるよう、ブログ機能も追加しました。  
固すぎず、またポップになりすぎない、デザインにしたくて、配色は海外の動物保護施設サイトを参考にしました。  
情報をしっかり読んでもらうことを優先し、過度なアニメーションは使用せず、ボタンホバーなど必要最低限に抑えました。
掲載画像は『O-DAN』で提供されている素材を使用し、画像容量の大きいものは表示の高速化を考慮してWebP形式へ変換しています。
